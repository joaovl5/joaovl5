Although the above text might *slightly* overshoot my actual velocity, I still like moving fast, while moving fast in a correct way! I enjoy investing in automations and tooling, so I can move faster while also avoiding falling. *(No wonder I use Neovim!)* What the above text doesn't exaggerate, however, is the raw joy I find in writing code and building quality stuff for people.

But I suppose these goals are somewhat incidental. Speed is great, building for the end result's sake is great too, but I also always just liked to tinker with things, learn how they work, and a natural byproduct of understanding these things better is working faster and with less headaches. Regardless of how detached something might appear from other interests, they often form surprisingly useful and tangible connections. Case in point: having written a [compiler](https://github.com/joaovl5/winter) actually helped me in designing a document processing systems that uses applied AI techniques at work, by thinking of some components of that system as sort of a compiler itself, and it's something I never could've thought without that random insight from a side-project.

In short, I like computers!
